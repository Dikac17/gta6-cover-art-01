PALMERA BAY — an offline web app that turns your photos and a caption into multi-panel cover art in the style of GTA 6's posters: upload 1–3 photos (or try the samples), pick a Hero, Split, Poster or Grid layout, crop and position each panel, edit the bold caption, choose a Sunset, Neon Night, Golden Hour or Noir colour grade, and export a PNG in 1080×1080, 1080×1350 or 1920×1080 to share. Everything runs on your own machine — no network, nothing uploaded. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC. See the bounty: https://make.fun/bounty/gta6-cover-art-01

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
